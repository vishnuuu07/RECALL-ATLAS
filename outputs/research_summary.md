# Recall Atlas — public evidence snapshot v0.3

**Data:** 24 unique publishable records from Reddit (12), Google Photos Community (9), PIXLS.US (2, cross-product context) and Google Play (1, uncertain). 23 are DIRECT/RELATED under deterministic coding; 12 are E1/E2. This is a purposive, retrieval-enriched sample, not representative platform telemetry or independently audited user episodes.

## Four distinct questions worth testing

1. **Collection/context scope:** A group/album/event clue does not consistently map to a bounded search path. Example: `reddit-1aju75m`; counterexamples include album-title-plus-term `community-128230954` and browser Find `community-162522212`.
2. **Literal text vs semantic query:** Screenshot/filename descriptions sometimes yield broad rather than literal matches. `reddit-1i06lg2` reports a successful quoted-text workaround; inspect existing capability before proposing something new.
3. **Candidate-to-nearby navigation:** `reddit-1h09vho` asks for surrounding-day access after a search; `reddit-1fmvxd6` describes month/year browsing. Neither establishes a verified target recovery outcome.
4. **Result completeness:** `reddit-1ov9y8d` and other posts report sparse/irrelevant results, but source data cannot isolate account, backup, index, interface or query factors.

## Non-findings

No production retrieval baseline, population prevalence, independent label-accuracy measurement, confirmed root cause, verified target presence or controlled improvement in success is available. Need 5–6 interviews and consented task observation before final problem selection.
